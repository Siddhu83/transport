# College Transport System - Frontend

React 19 + Vite + Tailwind CSS v4 + MapLibre GL JS WebGL map engine application.

## Sub-applications / Personas:
- **Student Mobile PWA:** Bottom sheet navigation, vector map, stop arrival awareness.
- **Driver Kiosk:** High-contrast night-mode, 1-tap SOS trigger with 2-second progress ring.
- **Super Admin Control Tower:** Incident room HUD, 60-100 vehicle status roster, 1-click relief rerouting.
